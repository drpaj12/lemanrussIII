# Note on SHA256SUMS.gz

`SHA256SUMS.gz` covers the private release directory, whose `DATASHEET.md` differs from the
`DATASHEET.md` in this repository: the public form omits per-set and per-benchmark infected/clean
counts (answer-key content). Every other listed file is unchanged. The checksum of `DATASHEET.md`
here therefore does not match the listed one.
