## Agent defaults taken during B/C/D (logged, continued from the list above)

6. insert_netlist.py/insert_hdl.py scoped to CombRareTrigger and the three bit-level payloads
   this round; the other two triggers and two payloads are modelled in A but need new
   free-running state (a counter, an FSM, a ring, a delay chain) the inserters do not build yet.
7. build.py's automatic site selection needs a design's candidate internal nets marked
   (* keep *) in the HDL: Odin III's Simulation.signals() does not list a purely combinational
   internal net otherwise (confirmed by running it, not assumed; see build.py's module
   docstring). A design without such a mark correctly reports "no rare net found" rather than
   silently picking a worse site.
8. write_blif --gates-as-names does not keep a kept wire's HDL name in the written net
   (--name-style provenance would, but needs --vtr, which refuses --gates-as-names);
   blif_text.net_name_by_cname_prefix recovers the written name from write_blif's own
   .cname <wire>.<generator> line instead.
9. build.py's "fires" and equivalence checks brute-force every primary-input combination
   (_BRUTE_FORCE_MAX_INPUTS = 20) because the Simulation API can only set a primary input
   directly, not an internal net; a wider design needs a real SAT/ATPG step, not enumeration.
